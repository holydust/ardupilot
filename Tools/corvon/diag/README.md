# CORVON G 系列 · SWD 板级诊断

给 `test` 报 `mag: FAIL n=0` 这一类"器件不应答"的情况用。产线烧录时 SWD 探针本来就在位,
所以这两条判据不需要拆板、不需要示波器。

```bash
./i2c-diag.sh          # scan + pullup,默认全跑
./i2c-diag.sh scan
./i2c-diag.sh pullup
```

CPU 会被 halt,跑完自动还原引脚配置并 `reset run`。

## scan —— 总线上有没有东西应答

把 PB6/PB7 从 I2C1 的 AF 切成开漏 GPIO,手工敲 I2C 时序扫 `0x08–0x77`。
I2C 没有最低时钟要求,SWD 一次访问几毫秒完全合法。
扫描前先发 9 个时钟 + STOP,释放可能卡在半个字节里的从机。

| 结果 | 含义 |
|---|---|
| 无任何 ACK | 器件不在总线上(没贴 / 虚焊 / 链路断) |
| 在预期地址 ACK | 器件正常,问题在别处(驱动、时序、参数) |
| 在别的地址 ACK | 地址脚(IST8310 的 `CAD0`/`CAD1`)接错或虚焊 |

## pullup —— scan 回答不了的那个问题

**读到 SCL/SDA 是高,本身什么都不能证明。** 模拟开关断开时 MCU 引脚悬空,
开关引脚到 V+ 的 ESD 二极管靠漏电流就能把它拉到 1。

所以这条测试改为:**把线拉低,然后释放** —— 只有真实存在的上拉才能把它拽回高。
并且在 RS2058 被命令到 MCU 侧和 FC 侧两种状态下各做一次:FC 侧回不来,
正好作为对照,证明开关确实在切换、测试本身有效。

```
开关 → MCU 侧:  拉低释放后 SCL=0 SDA=1   ← SDA 那一路完好,SCL 那一路断
开关 → FC  侧:  拉低释放后 SCL=0 SDA=0   ← 对照组,FC 未接,本来就没上拉
```

I2C 的 SCL 是开漏,**没有上拉就永远产生不了高电平**,任何地址都不会 ACK ——
一条 SCL 上拉缺失就足以解释"扫描全空"。

## 2026-08-20 G2 首片:这两条各自抓到了什么

`test` 报 `mag: FAIL n=0`。先核过固件与原理图,两块板一致,`corvon.init()`
在 `compass.init()` 之前完成模拟开关切换,不存在竞态;IST8310 地址脚
`CAD1→3V3 / CAD0→GND` = `0x0E`,与 hwdef 一致。

`scan` 全空。当时据"空闲读到高 ⇒ 链路完整"判为 U6 焊接不良,**这个推断是错的** ——
回流 U6 后 `scan` 依旧全空。`pullup` 才把故障定位到 **SCL 单边**:

```
MCU_SCL = { U5.9(mux NO1), U7.58(PB6) }     ← 网表确认 MCU 侧没有任何上拉
3V3 ─[RS1 4.7K]─ SCL_MAG ─[R19 10R]─ U5.COM1 ══开关1══ U5.NO1 ─ PB6
                    │                    ↑
                  U6.1(SCL)          IN1 ←[R21 10R]← PA6
```

嫌疑收敛到 `RS1` / `R19` / `R21` / U5 开关1 —— 全是 0201 无源件,与 IST8310 无关。

**教训:凡是"读到高/读到低"的单点电平判据,先问一句这个电平还能从哪来。**
悬空 + ESD 二极管漏电是最容易被当成"正常"的一种。

# SWD 连不上时的判据

OpenOCD 报 `init mode failed (unable to connect to the target)`,`-d3` 下的底层错误是
`STLINK_JTAG_GET_IDCODE_ERROR`。

**含义只有一个:狗发完 SWD 时序,SWDIO 上一个 bit 都没回来。** 调试端口(DP)是独立于
内核的硬件 —— 空片、锁死、跑飞、时钟没起,**任何内核状态下 IDCODE 都读得出来**。
读不到就是线级不通,不必去查固件、时钟或 flash 状态。

## 先做反向对照,别单向排查

**把同一套探针 + 同一套飞线接到一块已知好的板子上。**

- 好板能连 → 探针、飞线、插位、命令全部排除,故障锁在被测板
- 好板也连不上 → 与被测板无关,查探针侧

这一步花两分钟,能砍掉一半的排查空间。2026-08-21 我们绕了很久才做,不该。

## 两个没有分辨力的判据 —— 别用

| 测法 | 为什么无效 |
|---|---|
| **通电,量 `C` 焊盘对 GND 电压** | 内部下拉、对地短路、悬空焊盘 **三种都读 ≈0V**。万用表本身是 10MΩ 对地,悬空节点一接表笔就被拉到 0 |
| **断电,量焊盘对 GND 电阻** | 内部上下拉由 VDD 供电,**断电时根本不存在**;好板子同样读几 MΩ。唯一有效信息是排除硬短路(<1Ω) |

`D`(SWDIO)通电读到 3.3V 是**有效**的 —— PA13 复位后内部上拉,悬空焊盘产生不了它。
但 `C`(SWCLK)是下拉,没有对应的正判据,**两个焊盘不对称,不要一起下结论**。

## 有分辨力的判据:二极管档测 ESD 钳位

MCU 每个 IO 到 VSS 都有一个 ESD 二极管(阳极在 VSS)。**只要焊盘连到裸片就测得到,
走线断了就测不到**,而且不依赖供电状态、不依赖内部上下拉。

```
断电,万用表二极管档 🔺
  红笔 → G 焊盘    黑笔 → C 焊盘
  红笔 → G 焊盘    黑笔 → D 焊盘      ← 另一个引脚做对照组
```

| 读数 | 含义 |
|---|---|
| 两个都 ≈ 0.4–0.75V | 两个焊盘都连到裸片,板内走线完好 |
| 一个 OL、另一个导通 | OL 那一路的焊盘/走线断了,从 MCU 引脚直接飞线绕开 |

**必须带对照组。** 单独一个 0.7V 读数说明不了什么 —— 有对照才知道这块板的"正常值"
长什么样。

## 2026-08-21 G2 首片:全部排除,仍然连不上

U6 热风返修后 SWD 失效。逐项排除:

| 已排除 | 依据 |
|---|---|
| 探针损坏 | G1 用同一套探针+飞线一次连上,寄存器全读出 |
| 飞线、插位 | 同上 |
| 板子没电 | 灯语在跑,`D` 焊盘 3.3V |
| `C` 对地短路 | 断电 6.56 MΩ |
| 焊盘↔MCU 走线断 | 二极管档 `C`=0.734V / `D`=0.408V,两条都导通 |

**排除完了仍然连不上**,剩下两条万用表测不出来的:飞线与焊盘之间的接触点、
PA14 输入缓冲器损伤(ESD 二极管与下拉是独立结构,可以完好而输入级已失效)。板转维修部。

期间还犯过一次因果推断错误:曾怀疑"`C` 对地短路时反复 probe 打坏了探针输出级"
—— G1 对照实验直接证伪。**在拿到对照数据之前不要给硬件定罪。**
